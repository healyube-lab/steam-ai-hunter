# Steam AI Hunter

**Steam AI Hunter** — microservice aggregator for Steam discounts with AI-powered review analytics.

A lightweight, cross-platform ecosystem that parses Steam prices, enriches them with AI verdicts, and renders them in a responsive dashboard with tab-based filtering.

---

## Project Structure

```
steam_ai_hunter/
├── parser/                  # Go microservice: Steam price & discount scraper
│   └── main.go
├── ai_critic/               # Python microservice: AI verdict generator
│   └── main.py
├── frontend/                # HTML5 + Tailwind CSS + Vanilla JS dashboard
│   └── index.html
├── games_data.json          # Raw Steam game data (generated by parser)
├── analyzed_games.json      # Enriched game data with AI verdicts (generated by ai_critic)
└── README.md
```

---

## Architecture

| Layer | Technology | Responsibility |
|-------|-----------|----------------|
| **Parser** | Go | High-performance, concurrent fetching of Steam store API. Chosen for fast HTTP I/O, compiled binary efficiency, and easy Dockerization. |
| **AI Critic** | Python | Rule-based AI verdict engine. Chosen for rapid data processing, simple JSON handling, and extensibility for future ML model integration. |
| **Frontend** | HTML5 / Tailwind CSS / Vanilla JS | Responsive dashboard with tab filters ("All games" / "With discounts"). No build step — runs directly in any modern browser. |

**Data Flow:**

```
Steam Web API  →  Go Parser  →  games_data.json
                                           ↓
                              Python AI Critic  →  analyzed_games.json
                                           ↓
                                    Tailwind JS Dashboard
```

---

## Features

- Real-time Steam price and discount scraping (USD region, `cc=us&l=en`)
- AI-generated verdicts per game (free games, high discounts, no discount)
- Tab-filtered dashboard: view all games or only those with active discounts
- Rate-limit friendly: 300 ms delay between API requests
- Zero-dependency frontend — open `index.html` directly or serve via any static server

## Quick Start (Windows)

### Prerequisites

- **Go** 1.21+ — https://go.dev/dl/
- **Python** 3.9+ — https://www.python.org/downloads/windows/

### Step 1 — Run the Go Parser

Open PowerShell in the `parser` directory:

```powershell
cd C:\ПРОЕКТЫ\steam_ai_hunter\parser
go run main.go
```

This fetches prices for 30 popular Steam games and writes `../games_data.json`.

### Step 2 — Run the AI Critic

Open PowerShell in the `ai_critic` directory:

```powershell
cd C:\ПРОЕКТЫ\steam_ai_hunter\ai_critic
python main.py
```

This reads `games_data.json`, assigns AI verdicts, and writes `../analyzed_games.json`.

### Step 3 — Launch the Dashboard

Option A — open directly in browser:
```powershell
start C:\ПРОЕКТЫ\steam_ai_hunter\frontend\index.html
```

Option B — serve via Python HTTP server (recommended):
```powershell
cd C:\ПРОЕКТЫ\steam_ai_hunter\frontend
python -m http.server 8000
```
Then open `http://localhost:8000` in your browser.
